# OpenWrt для Vinga WR-AC1210GU (плата с флешкой 16 МБ)

**Язык:** [English](README.md) · [Українська](README.uk.md) · **Русский**

Неофициальная сборка **на основе OpenWrt 25.12.5**. Не является продуктом проекта OpenWrt и
не поддерживается им. Всё, что здесь описано, проверено на двух реальных роутерах, но
прошиваете вы на свой страх и риск.

## 1. Требования — прочитать обязательно

| Что | Нужно | Почему |
|---|---|---|
| SPI-флешка | **16 МБ** (W25Q128 или совместимая) | образ ~12 МБ, раздел прошивки рассчитан на 16 МБ. На стоковые 8 МБ не влезет |
| Загрузчик | **Breed** (MT7621) | ставить и восстанавливать прошивку; стоковый загрузчик JCG не проверялся |
| Раздел Factory | **родной** (с калибровкой этого роутера) | от него зависят мощность Wi-Fi, MAC и режим DBDC, см. [раздел 6](#6-раздел-factory-калибровка-wi-fi-mac-режим-dbdc) |
| Память | ничего делать не нужно | на плате уже стоят 256 МБ, OpenWrt видит их все (сток использовал только 128) |
| Инструменты | программатор SPI (CH341A + прищепка SOIC8), паяльная станция для замены флешки | без них ни флешку не поменять, ни роутер не оживить при ошибке |
| Связь | ПК с кабелем в LAN, статический адрес 192.168.1.2/24 | Breed отдаёт веб-морду на 192.168.1.1 без DHCP |

**Без программатора и снятого полного дампа родной флешки ничего не начинайте.** В дампе
лежит заводская калибровка Wi-Fi именно вашего роутера, и второй такой нет нигде.

## 2. Железо

| | |
|---|---|
| Модель / ODM | Vinga WR-AC1210GU = JCG JIR-AC680M (сток: `model=JIR-AC680M`, `customerId=102`) |
| Ближайший родственник в OpenWrt | JCG JHR-AC876M (та же разводка кнопок, диодов и портов) |
| SoC | MediaTek MT7621A, 2 ядра / 4 потока, 880 МГц |
| Wi-Fi | **один** MT7615 в режиме DBDC: 2.4 ГГц 2×2 + 5 ГГц 2×2 (4 антенны, по 2 на диапазон). PCIe port 0 |
| Память | **256 МБ DDR3** (Samsung K4W2G1646C-HC12, 2 Гбит x16) — стоят с завода. Стоковая прошивка JCG видит только **128 МБ** (размер зашит в её ядре); padavan и OpenWrt видят все 256 |
| Флешка | сток 8 МБ SPI → доработка 16 МБ (Winbond W25Q128) |
| Ethernet | 4 × LAN + WAN, гигабит (свитч MT7530 в SoC) |
| USB | 1 × USB 3.0 |
| Консоль | UART, `ttyS0`, 115200 8N1 |
| Диод питания | на 3.3 В напрямую, программно не управляется |
| Индикаторы | синие SMD-диоды; на этих платах **часто бывают сгоревшие** — см. [7.1](#71-сгоревшие-диоды) |

## 3. Доработка платы: флешка

### 3.1. Порядок

1. **Снять полный дамп родной флешки программатором** (8 МБ) и сохранить в двух местах.
   Проверить, что два чтения подряд дают одинаковый файл (`md5sum`).
2. Выпаять родную 8 МБ флешку, впаять 16 МБ (W25Q128). Удобно сразу поставить панельку SOIC8.
3. Собрать образ для новой флешки (ниже) и записать его программатором.
4. Включить роутер с зажатой кнопкой WPS → откроется Breed → залить прошивку
   ([раздел 10](#10-первая-прошивка-и-обновление)).

Память паять не нужно: на плате уже стоит чип на 256 МБ (Samsung K4W2G1646C-HC12, 2 Гбит).
Стоковая прошивка просто использует половину — объём 128 МБ зашит в её ядре. OpenWrt определяет
память сам и видит все 256 МБ (`free -m` → около 240 МБ в строке Mem).

### 3.2. Образ для новой 16 МБ флешки

Нужны: `breed.bin` (192 КБ, см. [раздел 5](#5-загрузчик-breed)) и полный дамп родной флешки
`stock8.bin`. В стоке Factory лежит по тому же адресу `0x40000`.

```sh
# пустая 16 МБ «флешка» (все байты 0xFF)
dd if=/dev/zero bs=1M count=16 | tr '\000' '\377' > new16.bin
# 0x0: загрузчик Breed
dd if=breed.bin  of=new16.bin conv=notrunc
# 0x40000: родной Factory из стокового дампа (64 КБ)
dd if=stock8.bin of=new16.bin bs=64k skip=4 seek=4 count=1 conv=notrunc
# проверка: MAC в Factory (смещение 0x4) должен быть «настоящим», не 00:0C:43:…
dd if=new16.bin bs=1 skip=$((0x40004)) count=6 2>/dev/null | od -An -tx1
```

Config (`0x30000`) и прошивка (`0x50000`…) остаются пустыми: Breed создаст свои настройки,
а прошивку зальём через его веб-морду.

## 4. Разметка флешки

| Адрес | Размер | Раздел (OpenWrt) | Что там |
|---|---|---|---|
| `0x000000` | 192 КБ | `u-boot` (только чтение) | Breed |
| `0x030000` | 64 КБ | `u-boot-env` (только чтение) | настройки загрузчика (Config) |
| `0x040000` | 64 КБ | `factory` (только чтение) | калибровка Wi-Fi, MAC |
| `0x050000` | 15.7 МБ | `firmware` | ядро + squashfs + `rootfs_data` (jffs2, настройки) |

`IMAGE_SIZE := 16064k` (= `0xFB0000`). Раздел `factory` из OpenWrt **не записывается** —
менять его только через Breed.

## 5. Загрузчик Breed

**Breed** — закрытый, но бесплатный загрузчик от HackPascal для MediaTek/Ralink. Он не стирается
при прошивке, имеет веб-морду для заливки прошивки, загрузчика, Factory и полного образа флешки
и даёт снять резервные копии. Это главная «страховка» роутера.

- **Бинарник Breed в этот репозиторий не входит**: у него нет открытой лицензии.
  Скачивайте с сайта автора: **https://breed.hackpascal.net/** — файл
  **`breed-mt7621-pbr-m1.bin`** (вариант «PandoraBox PBR-M1 / Newifi Y2S»),
  прямая ссылка: https://breed.hackpascal.net/breed-mt7621-pbr-m1.bin
- Почему именно этот вариант: у PBR-M1 кнопка восстановления на **GPIO18**, а у Vinga на GPIO18
  висит **WPS**. С другим вариантом Breed может ждать другую кнопку — войти в него не получится.
- Проверенные ревизии:

  | | Наша (на роутерах) | На сайте (10.10.2026) |
  |---|---|---|
  | Версия | 1.1 **r1266**, сборка 2018-12-29 | 1.1 **r1337**, сборка 2021-12-15 |
  | md5 | `98027bd18894a424e9e85c0a479eb63b` | `24e62762809c15ba3872e610a37451a3` |
  | Размер файла | 196 608 (дополнен до 192 КБ) | 105 107 |
  | Плата (`Board:`) | PandoraBox PBR-M1 / Newifi Y2S | то же |
  | Инициализация DDR (первая ступень) | эталон | **совпадает с r1266 байт в байт** |
  | Winbond W25Q128 | поддерживается | поддерживается (+26 новых чипов) |
  | Прошита на Vinga | **да** | нет, только сравнение образов |

  По сравнению r1337 отличается кодом загрузчика (исправления, новые флешки), а вариант платы
  (значит, и кнопка GPIO18) и инициализация памяти те же — должна работать так же. После прошивки проверьте версию и
  строку `Board:` на главной странице Breed.
- Раздел загрузчика — 192 КБ (`0x30000`). Файл с сайта меньше: при записи программатором
  остаток раздела заполняется `0xFF` (команда `dd … conv=notrunc` из раздела 3.2 так и делает).
- Веб-морда Breed по умолчанию на китайском. Перевод на английский мы делали заменой строк
  внутри распакованного LZMA-образа (без сдвига адресов, контрольной суммы у образа нет) —
  английский бинарник тоже не публикуем, т. к. это изменённая чужая программа.

### Как войти в Breed

1. Выключить роутер, **зажать WPS**, включить питание, держать 3–5 с.
2. ПК в LAN, статический адрес `192.168.1.2/24`, открыть `http://192.168.1.1`.

### Что делать в Breed первым делом

- **Резервная копия → полный образ флешки (Full flash)** и **EEPROM (Factory)** — сохранить на ПК.

### Поля страницы «Обновление прошивки»

| Поле | Что пишется | Factory трогает? |
|---|---|---|
| **Firmware** | только раздел прошивки с `0x50000` | нет |
| **EEPROM** | только Factory (64 КБ) | да |
| **Bootloader** | только загрузчик | нет |
| **Full flash** (программаторный образ) | всю флешку из файла: загрузчик, Config, Factory | **да** |

Для OpenWrt нужно **только поле Firmware**.

## 6. Раздел Factory: калибровка Wi-Fi, MAC, режим DBDC

### 6.1. MAC-адреса (схема стока)

| Смещение в Factory | Что | Значение |
|---|---|---|
| `0x0004` | базовый MAC (Wi-Fi) | `X` |
| `0xE000` | LAN | `X − 1` |
| `0xE006` | WAN | `X − 2` |

5 ГГц в OpenWrt получает `X + 1`, 2.4 ГГц — `X`.

### 6.2. Режим DBDC — байт `0x3E`

Открытый драйвер **mt76** решает, работать ли в DBDC (оба диапазона одновременно), **только по
байту `0x3E` в Factory**: биты 5:4 = 3, то есть значение **`0x30`**.

- `0x30` — две сети (`phy0` = 2.4 ГГц, `phy1` = 5 ГГц). Так в заводском Factory Vinga.
- `0x00` — одно радио «2.4 или 5». Так в шаблонном Factory из SDK MediaTek.

Закрытый драйвер padavan этот байт игнорирует (DBDC включается сборкой), поэтому на padavan
проблему не видно.

Проверка в OpenWrt:

```sh
cat /sys/kernel/debug/ieee80211/phy0/mt76/dbdc   # должно быть 1
iw list | grep ^Wiphy                            # phy0 и phy1
```

Если байт неправильный — исправить в копии Factory (`printf '\x30' | dd of=factory.bin bs=1 seek=$((0x3e)) conv=notrunc`)
и залить через Breed → EEPROM, затем на роутере `rm /etc/config/wireless; wifi config`.

### 6.3. Калибровка и «донорские» Factory

По сети ходят Factory «от другой Винги». Тот, что попадался нам, оказался **шаблоном SDK**, а не
заводской калибровкой: MAC-заглушка `00:0C:43:26:60:A8` (префикс Ralink), одинаковые мощности
`0x14` на всех каналах без поправок, `0x3E = 0x00`.

| Factory | 5 ГГц Tx-Power в OpenWrt | Что видно на практике |
|---|---|---|
| шаблон SDK («донор») | 16 dBm | вблизи нормально; на краю роутер передаёт на 40 МГц вместо 80 |
| заводской (свой) | 20–21 dBm (дальше ограничивает страна) | вблизи MCS 9 (866.7 Мбит/с) в обе стороны |

Если своей калибровки нет (умерла родная флешка без дампа), лучше взять **заводской Factory с
другой платы этой же модели** и вписать в него свои MAC (`0x4`, `0xE000`, `0xE006`) — это точнее
шаблона. Мощность на отдельных каналах может отличаться на 1–2 дБ.

## 7. Кнопки, диоды, порты

| GPIO | Назначение | |
|---|---|---|
| 3 | диод USB | active-low, триггер `usbport` |
| 13 | диод 2.4 ГГц | active-low, `phy0radio` |
| 14 | диод WPS | active-low; мигает при загрузке/прошивке |
| 15 | диод 5 ГГц | active-low, `phy1radio` |
| 16 | кнопка **Reset** (утопленная) | |
| 18 | кнопка **WPS** (выступающая) | ею же входят в Breed |

- Порты: **LAN1…LAN4 = порты свитча 0…3**, **WAN = PHY4 через GMAC1**.
- Диоды портов LAN/WAN — внутри свитча MT7530, в `/sys/class/leds` их нет; гасятся через
  регистры PHY (`mdio-tools`), см. `files/usr/bin/leds`.

### Поведение кнопок в этой сборке

| Кнопка | Действие |
|---|---|
| **WPS** коротко (< 2 с) | все диоды вкл/выкл (включая порты) |
| **WPS** 2–8 с (через 2 с диод WPS мигает) | 2.4 ГГц вкл/выкл (сохраняется) |
| **WPS** — свои действия | настраиваются в LuCI: *Службы → Диоды и кнопка* |
| **Reset** коротко | ничего |
| **Reset** ≥ 15 с (через 15 с WPS мигает) | сброс настроек |

### 7.1. Сгоревшие диоды

Заводские синие диоды на платах Vinga **часто выгорают**. Если какой-то индикатор не светится,
прежде чем паять, убедитесь, что дело в диоде, а не в настройке:

```sh
ls /sys/class/leds/                          # имена диодов, например blue:wps
echo none > /sys/class/leds/blue:wps/trigger
echo 1    > /sys/class/leds/blue:wps/brightness   # должен загореться
echo 0    > /sys/class/leds/blue:wps/brightness
```

Если GPIO переключается, а диод молчит — он сгорел, меняйте.

- **Подходит синий SMD-диод типоразмера 0603** — встаёт на заводские площадки идеально.
  0805 и 1206 крупнее, на эти площадки садятся плохо.
- Соблюдайте полярность: катод отмечен меткой на корпусе; проверяйте мультиметром в режиме
  «диод» до пайки.
- Резисторы на плате остаются заводские — менять только сам диод.
- Колонка фронтальных диодов на плате: D30 (USB, крайний), D17, D15, D13, D9.

## 8. Что входит в прошивку

### 8.1. Пакеты (`diffconfig`)

- LuCI на русском и украинском;
- флешки и ФС: `block-mount`, ext4, vfat, exfat, ntfs3, `e2fsprogs`, `dosfstools` (для extroot);
- VPN: WireGuard, OpenVPN (mbedTLS); **pbr** (маршрутизация по доменам через VPN), `ip-full`,
  `dnsmasq-full`;
- ИБП: NUT (сервер, upsmon, драйверы `usbhid-ups`, `nutdrv_qx`);
- USB-модемы и раздача интернета с телефона (RNDIS, QMI, NCM, MBIM, `usb-modeswitch`);
- `nlbwmon`, `https-dns-proxy`, `watchcat`, WoL, принтер `p910nd`, `curl`, `htop`, `nano`, `iperf3`,
  `mdio-tools`.

Сознательно **не** включены (ставятся из репозитория при нужде): `ttyd` (тянет OpenSSL),
`luci-app-nut` (тянет графические библиотеки), `usbutils`, `mc` (тянет glib2, ~2 МБ — ставьте на
extroot).

### 8.2. Свои пакеты (`packages/`)

| Пакет | LuCI | Что делает |
|---|---|---|
| `tgnotify` + `luci-app-tgnotify` | *Службы → Telegram* | сообщения в Telegram: подключение WAN/резервного канала, вход по SSH. `tg_say "текст"` из консоли. Токен хранится в `/etc/config/tgnotify` с правами 600 |
| `wifitimer` + `luci-app-wifitimer` | *Службы → Расписание Wi-Fi* | выключение **отдельных сетей (SSID)** по расписанию: например, 5 ГГц ночью, а 2.4 ГГц для умного дома работает |
| `ledtimer` + `luci-app-ledtimer` | *Службы → Диоды и кнопка* | кнопки «погасить/зажечь все диоды», расписание диодов, действия кнопки WPS (диоды, 2.4/5 ГГц, весь Wi-Fi, OpenVPN, переподключение WAN, перезагрузка, свой скрипт) |

Общие правила расписаний: период может переходить через полночь; день — это день **начала**
периода; таймер срабатывает только на переходах, поэтому ручное включение/выключение живёт до
следующего переключения по расписанию; перед первым действием ждёт синхронизации времени (NTP).
Журнал: `logread | grep -E 'wifitimer|ledtimer|wps-button'`.

### 8.3. Свои файлы прошивки (`files/`)

| Файл | Что делает |
|---|---|
| `etc/uci-defaults/99-vinga` | один раз после прошивки/сброса: аппаратное + программное ускорение NAT, packet steering, Wi-Fi страна UA и 5 ГГц 80 МГц, IPv6 выключен, WAN — DROP, пинг с WAN выключен |
| `etc/rc.button/wps`, `etc/rc.wps/10-vinga` | кнопка WPS с подсветкой (см. выше) |
| `etc/rc.button/reset` | Reset: короткое — ничего, ≥ 15 с — сброс |
| `usr/bin/leds on\|off\|toggle` | все диоды, включая диоды портов |
| `etc/banner` | приветствие при входе по SSH |

`99-vinga` выполняется **и после обновления с сохранением настроек** — после обновления
проверьте страну Wi-Fi.

## 9. Сборка

### 9.1. Зависимости (Ubuntu 24.04)

```sh
sudo apt install build-essential clang flex bison g++ gawk gettext git \
  libncurses-dev libssl-dev python3-dev python3-setuptools rsync swig \
  unzip zlib1g-dev file wget
```

### 9.2. Сборка

```sh
git clone https://github.com/ironglass-lab/openwrt-vinga-wr-ac1210gu.git
cd openwrt-vinga-wr-ac1210gu
bash build.sh
```

`build.sh`: клонирует OpenWrt `v25.12.5` в `openwrt/`, накладывает патч платы, копирует `files/`
(с исправлением прав), копирует `packages/` в `openwrt/package/`, обновляет feeds, кладёт
`diffconfig` в `.config`, `make defconfig`, собирает.

Нужно ~20 ГБ места, первая сборка ~1–1.5 ч. Результат:

```
openwrt/bin/targets/ramips/mt7621/*vinga_wr-ac1210gu-squashfs-sysupgrade.bin
```

### 9.3. Проверка образа перед прошивкой

```sh
cd openwrt
f=$(ls bin/targets/ramips/mt7621/*vinga_wr-ac1210gu-squashfs-sysupgrade.bin)
off=$(grep -obUaP "hsqs" "$f" | head -1 | cut -d: -f1)
tail -c +$((off+1)) "$f" > /tmp/root.sqsh
unsquashfs -lls /tmp/root.sqsh | grep -E "squashfs-root(/etc|/usr)?$|bin/(leds|wifitimer|ledtimer)$|rc.wps/"
```

У `squashfs-root`, `/etc`, `/usr` должно быть **`drwxr-xr-x`** (см. [грабли](#13-грабли)), плагины —
на месте.

### 9.4. Название сборки

В `diffconfig` задано своё имя дистрибутива, чтобы сборку не путали с официальной OpenWrt:

```
CONFIG_IMAGEOPT=y
CONFIG_VERSIONOPT=y
CONFIG_VERSION_DIST="Vinga-WRT"
CONFIG_VERSION_MANUFACTURER="Ironglass"
CONFIG_VERSION_MANUFACTURER_URL="https://ironglass.com.ua"
CONFIG_VERSION_HOME_URL="https://github.com/ironglass-lab/openwrt-vinga-wr-ac1210gu"
CONFIG_VERSION_SUPPORT_URL="https://github.com/ironglass-lab/openwrt-vinga-wr-ac1210gu/issues"
```

Имя видно в LuCI (*Состояние → Обзор*, нижняя строка) и в `/etc/openwrt_release`; от него же
начинается имя файла образа (`vinga-wrt-…-sysupgrade.bin`).

### 9.5. Свои пакеты отдельно (apk)

```sh
cd openwrt
make package/wifitimer/compile package/luci-app-wifitimer/compile
find bin/packages -name "*wifitimer*.apk"
# на роутере:
apk add --allow-untrusted /tmp/*wifitimer*.apk
```

У LuCI-пакетов версия `0` (берётся из git) — при обновлении добавляйте `--force-reinstall`.
После изменения исходников пакета: `make package/<имя>/clean`.

## 10. Первая прошивка и обновление

### 10.1. Первая установка (через Breed)

1. Снять в Breed полный дамп и Factory ([раздел 5](#5-загрузчик-breed)).
2. Breed → обновление → **Firmware** → `…-squashfs-sysupgrade.bin` → обновить.
3. Подождать 3–4 мин. Диод WPS мигает при загрузке и гаснет, когда система готова.
4. `http://192.168.1.1`, логин `root` **без пароля** → сразу задать пароль.
5. Проверить DBDC ([6.2](#62-режим-dbdc--байт-0x3e)), страну Wi-Fi и мощность:
   `iwinfo phy1-ap0 info | grep -E "Channel|Tx-Power"`.

> До настройки роутер раздаёт DHCP в `192.168.1.0/24`. Не подключайте его LAN в уже
> работающую сеть с тем же диапазоном.

### 10.2. Обновление (LuCI)

*Система → Резервная копия / Прошивка → Обновить прошивку*: оставить «Сохранить настройки»,
включить «Создать список установленных пакетов».

- Перед обновлением проверьте, что нужные файлы вне `/etc/config` попадут в копию:
  `sysupgrade -l | grep -E "openvpn|crontabs|rc.local|profile.d"`. Недостающее — в `/etc/sysupgrade.conf`.
- В описании платы стоит `$(Device/dsa-migration)` → `compat_version 1.1`. Без этого обновление с
  сохранением настроек отказывает (`config is incompatible`).
- Пакеты, поставленные через apk (не входящие в прошивку), после обновления надо поставить заново.

### 10.3. Откат

- На padavan или прошлый образ: Breed → Firmware.
- Полностью «как было»: Breed → Full flash → полный дамп (вернёт и загрузчик, и Factory).
- Если не стартует даже Breed — программатор.

## 11. Флешка USB как extroot

Встроенной памяти под настройки остаётся ~3.9 МБ, пакеты удобнее держать на флешке.

### 11.1. Первая настройка

```sh
block info                          # найти флешку, например /dev/sda1
mkfs.ext4 -L extroot /dev/sda1      # ВНИМАНИЕ: стирает флешку
UUID=$(block info /dev/sda1 | sed -n 's/.*UUID="\([^"]*\)".*/\1/p')
uci set fstab.extroot=mount
uci set fstab.extroot.uuid="$UUID"
uci set fstab.extroot.target='/overlay'
uci set fstab.extroot.check_fs='1'
uci set fstab.rwm=mount
uci set fstab.rwm.device="$(sed -n -e '/\s\/overlay\s/s/\s.*//p' /etc/mtab)"
uci set fstab.rwm.target='/rwm'
uci commit fstab
mount /dev/sda1 /mnt && tar -C /overlay -cf - . | tar -C /mnt -xf - && umount /mnt
reboot
```

Флешка может быть и с данными (ext4): extroot ложится рядом в папки `upper/` и `work/`.

### 11.2. После обновления прошивки

При **первой** загрузке после обновления роутер стартует со встроенной памяти: настройки
распаковываются позже, чем ищется extroot. До следующей перезагрузки:

```sh
mount /dev/sda1 /mnt
mv /mnt/upper /mnt/upper.old && mv /mnt/work /mnt/work.old   # старое не удаляем сразу
tar -C /overlay -cf - . | tar -C /mnt -xf -
umount /mnt && reboot
df -h /overlay                                               # должен быть размер флешки
```

Потом заново поставить пакеты, которых нет в прошивке (`mc terminfo openssh-sftp-server` и т. п.).

## 12. Скорость и ограничения

Замеры iperf3, телефон Redmi Note 13 Pro 5G (2×2), 5 ГГц канал 100, 80 МГц:

| Условия | Загрузка / отдача, Мбит/с |
|---|---|
| 2 м от роутера, заводской Factory | ~600 / ~630, линк 866.7 (MCS 9, 2 потока) |
| то же на padavan (закрытый драйвер) | ~607 / ~633 |

- **Нет WED** (аппаратной разгрузки Wi-Fi): у MT7615 её нет. Аппаратный NAT (PPE) ускоряет только
  **проводной** трафик; Wi-Fi обрабатывает процессор. На максимальной скорости Wi-Fi нагрузка
  ~0.6 из 4 — потолок задаёт радио (2×2, 80 МГц), а не CPU. В padavan то же самое: `hw_nat` для
  Wi-Fi ускоряет только NAT, драйвер Wi-Fi и там на процессоре.
- **160 МГц** в режиме DBDC нет. Некоторые приложения (например, LuCI Mobile) всё равно предлагают
  эту ширину — не выбирайте, 5 ГГц не поднимется.
- **Beamforming** у mt76 для MT7615 нет; на краю покрытия закрытый драйвер padavan может быть
  немного быстрее.
- 5 ГГц на DFS-каналах (52–144): после включения минута проверки на радары.
- Мощность ограничивается Factory и выбранной страной (регдоменом). Выбирайте свою страну.

## 13. Грабли

1. **Права каталогов в `files/`.** Если папка `files/` создана с правами `700`, сборка перенесёт их
   на `/`, `/etc`, `/usr` образа. Ядро грузится, failsafe работает, а обычная загрузка встаёт
   (службы не от root не могут войти в `/`). `build.sh` выставляет 755/644 сам; проверка — [9.3](#93-проверка-образа-перед-прошивкой).
2. **Байт DBDC `0x3E`** — см. [6.2](#62-режим-dbdc--байт-0x3e).
3. **`ip-full` и `dnsmasq-full`** (нужны pbr) заменяют `ip-tiny` и `dnsmasq`. В diffconfig они
   прописаны вместе с `# … is not set` для старых вариантов; после `make defconfig` проверьте, что
   в `.config` нет `CONFIG_PACKAGE_ip-tiny=y` и `CONFIG_PACKAGE_dnsmasq=y`.
4. **Через apk нельзя ставить модули ядра из официального репозитория** — у самосборки другой
   `vermagic`. Нужные `kmod-*` включайте в сборку.
5. **`build.sh` каждый раз копирует `diffconfig` в `.config`** — правки только в `.config` пропадут.
6. **Обработчики hotplug с фоновыми процессами** (`( … ) &`) — только с перенаправлением
   `</dev/null >/dev/null 2>&1`, иначе загрузка может зависнуть.
7. **OpenVPN mbedTLS против старого сервера (OpenVPN 2.4 / OpenSSL 1.1.1)**: «TLS key negotiation
   failed» лечится `tls-version-max 1.2` в `.ovpn`. Если сервер пушит `redirect-gateway`, а нужен
   выборочный VPN — `pull-filter ignore "redirect-gateway"`.
8. **Чужой DHCP в LAN** выключает DHCP роутера (`dnsmasq` проверяет сеть) — `uci set dhcp.lan.force=1`.
9. **Busybox ash без Unicode**: Backspace после кириллицы «съедает» приглашение — это только
   отображение. Лечится `bash` или опцией Unicode в busybox при сборке.
